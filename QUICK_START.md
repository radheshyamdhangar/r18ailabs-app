# 🚀 QUICK START GUIDE

## Get Started in 30 Seconds

### Option 1: Run Locally

```bash
# 1. Navigate to project
cd E:\r18ailabs\untitled

# 2. Install dependencies (already done, but just in case)
npm install

# 3. Start development server
npm run dev

# 4. Open browser
# http://localhost:3000
```

### Option 2: Deploy to Vercel (2 minutes)

```bash
# 1. Push to GitHub
git add .
git commit -m "R18 AI LABS website"
git push

# 2. Go to vercel.com/new
# 3. Select your repository
# 4. Click "Deploy"
# Done! 🎉
```

## 🚀 Deploy in 3 Steps

### Step 1: Create GitHub Repo
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR/REPO
git push -u origin main
```

### Step 2: Connect to Vercel
- Go to vercel.com/new
- Click "Import Git Repository"
- Select your repo
- Click "Deploy"

### Step 3: Done! 🎉
- Your site is live
- Custom domain? Add in Vercel settings
- Auto-deploys on every push

## ❓ Troubleshooting

### Port 3000 in use?
```bash
npm run dev -- -p 3001
```

### Dependencies issues?
```bash
rm -rf node_modules package-lock.json
npm install
```

### Build failing?
```bash
npm run type-check
npm run lint
npm run build
```
